## Local Development Setup

To run this site locally on your machine:

```bash
# Clone the repository
git clone https://github.com/Aditya-Verma25/aditya-verma.com.git
cd aditya-verma.com

# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

Open <a href="http://localhost:8080" target="_blank" rel="noopener noreferrer">http://localhost:8080</a> in your browser to view the site.
